# Superstore Data Analysis

## About the Project

This project is an end-to-end data analysis project based on a Superstore dataset. The main purpose of this project is to understand the sales and business performance of the company through data.

I worked on the project in two main stages. First, I used Python for data cleaning, exploration, and analysis. After that, I created an interactive Power BI dashboard to present the important findings in a simple and visual way.

The project helped me understand how raw business data can be converted into useful insights that can support better business decisions.

---

## Project Objectives

The main objectives of this project are:

* To understand the structure and quality of the dataset.
* To clean and prepare the data for analysis.
* To perform exploratory data analysis using Python.
* To analyze sales, profit, quantity, orders, and discounts.
* To understand business performance across different categories and regions.
* To identify important trends and patterns in the data.
* To create an interactive dashboard using Power BI.
* To present the analysis in a clear and easy-to-understand format.
